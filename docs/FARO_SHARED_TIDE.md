# FARO Tide — shared model read

Both coasts use the existing shared console, original beacon, same score palette and local selected day/window. Open-Meteo sea_level_height_msl is a model of total sea level, not official astronomical tide; hourly extrema are approximate. Missing values are not filled. No numeric score adjustment until local calibration. Zeeland Cadzand-Bad guide: https://www.wompy.nl/spot/cadzand (high/rising; not transferred to west sector). Chile references: existing chile/regions/CL-VS.json publishedReference; not calibrated. Local knowledge from Ed: Cadzand harbour may shelter some wind; Dishoek–Vlissingen can work with strong north swell and north wind; 1 m and 6 s is a heuristic, not a cutoff. Official comparisons: https://www.rijkswaterstaat.nl/water/waterdata/getij and https://www.shoa.cl/; automated official tide ingestion not implemented. Older Chile caches without hourly series show unavailable until refresh.
